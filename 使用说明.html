宿经03超大CSV文件实用编辑器

快速打开、筛选、拆分、处理超大表格文件的桌面工具（Rust 重构版）

一、这个软件是做什么的

它专门用来打开和处理特别大的数据表文件（比如几百兆、几个 G 的 CSV / TXT 文件）。普通的表格软件打开这类文件会卡死、甚至崩溃，而这个软件可以几秒钟就读取并流畅浏览，还能帮你快速筛选、拆分和加工数据。

这个软件支持： 秒开超大文件 条件筛选 按行/按字段拆分 列增删改 行哈希校验 导出 CSV/XLSX Win7 免安装

二、认识软件界面

软件打开后主要分为以下几个区域：

区域作用
顶部菜单栏文件、编辑、视图、工具、数据处理、设置、帮助，几乎所有功能都能在菜单里找到（帮助 → 使用说明 可随时打开详细说明书）。
顶部工具栏常用的一键按钮：打开文件、多文件合并、导出数据、加载示例、清空数据、数据筛选、清除筛选、刷新显示、日志；其后是 ❤ 自愿捐助 与 按钮大小（界面等比放大倍数）。
数据处理工具栏主工具栏下方的一条工具栏，把「数据处理」菜单的全部命令做成了按钮：拆分数据、列操作（拆分/合并字段、生成行哈希、复制/插入/删除/隐藏/显示列）、撤销/恢复、清理筛选缓存、文件信息。可用菜单 工具 → 数据处理工具栏 显示或隐藏（默认显示，显示时该菜单项后面带 ✔）。
数据分析工具栏再下面一条工具栏，提供 提取唯一行（去重）；同一条命令也在菜单 数据分析 下。可用菜单 工具 → 数据分析工具栏 显示或隐藏（默认显示，显示时菜单项后带 ✔）。
中部数据预览展示表格内容，像网页一样流畅滚动查看上百 / 上千 / 上万行。双击某个单元格可查看这一行的完整数据。
右侧日志面板记录每一步操作的提示和结果，可清空、复制或导出成文本。
底部状态栏窗口最下方显示 总行数 / 筛选后行数 / 列数 / 当前内存占用，以及已打开文件的文件名、大小、编码。
进度小窗口处理大文件时显示进度条和百分比，可拖动位置。
窗口底部状态栏会显示：总行数、筛选后行数、列数、当前内存占用，以及文件名、大小、文件编码。打开文件后请先看一眼，确认确实读对了。

三、开始使用：从打开文件到导出

1. 打开文件

1
点击顶部工具栏的 📂 选择CSV文件，或菜单栏 文件 → 打开CSV文件。
2
在系统窗口中选择要打开的 CSV 或 TXT 文件（也可以直接拖放，或通过“所有文件”选其他后缀）。
3
等待几秒，自动识别文件编码并建立索引，随后表格内容出现在预览区。
如果你只是想先体验一下功能，可以点击 🧪 加载示例数据，软件会生成一份 1000 行的示例数据。

2. 一次打开多个 CSV 并合并

同一类数据如果分散在多个 CSV 里（例如按月导出的交易明细），可以合并成一个数据集，再统一筛选、拆分、导出。

1
点工具栏 📚 选择多个CSV文件（合并），或菜单 文件 → 打开多个CSV文件（合并）。
2
在系统窗口中一次选中多个文件；也可在弹出窗口点 ➕ 追加选择文件 继续添加，列表里能逐项「移除」或「清空列表」。
3
软件会先读取各文件表头并校验是否一致（此时尚未读取数据，速度很快）：
  • 表头完全一致 → 可以直接合并；
  • 字段相同、只是列顺序不同 → 自动按字段名对齐后合并；
  • 表头不一致 → 会列出差异字段，勾选 只保留相同字段名的字段进行合并，即按各文件共有的字段合并。
4
点 开始合并；完成后结果自动作为当前数据打开，需要留存时用 💾 导出数据 另存到指定位置。
合并只是把各文件的行依次接在一起，不会改动你的原始文件；列按字段名对齐，所以各文件列顺序不同也没关系。

3. 浏览数据

表格默认显示前 100 行。你可以在预览区拖动滚动条查看更多；双击任意单元格会弹出一个窗口，展示这一行的全部列-值对照，方便核对长文本或号码。

4. 筛选想要的数据

想只看到某类数据（如“某账号的交易记录”或“金额大于 100 的行”），用筛选功能。

1
点击 🔍 数据筛选 打开筛选窗口。
2
点击 + 添加条件，依次选择：字段（哪一列）、条件（等于/包含/大于…）、值。
3
加多条条件时，用 且 / 或 决定它们的关系。可点 ↑ / ↓ 调整顺序，× 删除某条。
4
点击 应用筛选，预览区只剩命中的行；顶部信息栏显示“筛选后”行数。
5
想恢复全部数据，点筛选窗口里的 清除筛选；工具栏上也有 🧹 清除筛选 按钮，不用打开窗口即可一键恢复。
条件含义举例
等于 / 不等于字段值精确等于 / 不等于某个值
包含 / 不包含字段值是否包含某段文字
大于 / 小于 / 大于等于 / 小于等于数值比较（长数字、大金额也能精确比较）
空值 / 非空值该字段是否为空白

5. 把大表拆成多个小文件

通过 数据处理 → 拆分数据…，有两种拆法：

  • 按行数拆分：每隔多少行生成一个文件（如每 10 万行一个）。
  • 按字段拆分：按某一列的取值分组，把相同值的行归纳到一个文件（如“按银行名称”拆）。可组合 1~3 列。

再选好输出格式（CSV / XLSX）和保存的文件夹，点 执行拆分 即可。

拆分完成后会自动生成核对表：输出文件夹里会出现 拆分完整性核对表.csv（可用 Excel 直接打开），里面写明拆分类型、拆分依据（每批行数或所按字段）、每个文件的数据行数、输出总行数、数据来源行数以及完整性核对结果，方便随数据一起存档与复核。
拆分结果可核对：每次拆分完成后，右侧「操作日志」会逐条列出每个文件的不计表头数据行数，接着给出「各文件合计行数」与「数据来源总行数」的对比，最后一行是完整性核对结论（显示 ✅ 完整性核对通过 就表示一行都没丢）。文件很多时只列出前 50 个，其余汇总为一行。

6. 对列做加工

通过 数据处理 → 列操作，可以：

操作说明
拆分字段把一列按分隔符拆成多列（如把“2021-12-30 00:00:00”拆成日期和时间）
合并字段把多列拼成一列
生成行哈希为每一行生成一串固定长度校验码（md5/sha1/sha256/sha512），用于核对数据是否被改动
复制 / 插入 / 删除列新增、删除、调整列
隐藏 / 显示列暂时隐藏某些列（不影响数据），方便看核心字段
列操作后，可在 编辑 → 撤销 / 恢复 或 数据处理 → 撤销 / 恢复 里反悔，多步都能退回。

7. 导出结果

1
先筛选出你想要的数据（不筛选就是导出全部）。
2
点 💾 导出数据，选择 CSV 或 XLSX 格式。
3
选择保存位置，软件在后台写出，并显示进度。
导出小知识：CSV 会带 BOM，用 Excel 打开中文不乱码；XLSX 全部按文本保存（卡号、账号、长数字、前导零都不会变成科学计数法或丢失精度，但 Excel 中不参与自动求和等计算）；超大结果会自动分成多个工作表。

8. 消除重复行（提取唯一行）

同一批数据里常有重复记录（例如同一条交易被多个来源重复采集）。要去掉重复行：

1
先按需要筛选出要处理的数据（不筛选就是全部数据）。
2
点「数据分析」工具栏上的 🔍 提取唯一行（去重）…，或菜单 数据分析 → 提取唯一行（去重）…。
3
在窗口里勾选判重字段：只勾"账号"就表示"账号相同的行视为重复"；一个都不勾 = 按全部字段判重（整行完全一样才算重复）。可用「全选 / 全不选」快速操作。
4
点 提取唯一行，完成后界面只剩唯一行 —— 顶部状态栏的"筛选后"行数与操作日志会显示去掉了多少重复行。
5
完成后会弹出提示窗，显示「判重范围 / 唯一 / 剔除」行数，并询问是否导出 重复行对应表（可选 CSV 或 XLSX）。
重复行对应表逐条记录：保留的首次出现行号 ↔ 被剔除的重复行号，并附上判重字段的取值，方便你抽查每一条去重是否正确；行号从 1 开始，与表格显示一致。
去重结果会成为当前的数据视图：接下来的导出、拆分、查看看到的都是唯一行。想回到完整数据，点工具栏 🧹 清除筛选 即可（原始文件不会被改动）。判定重复时保留第一次出现的那一行，所以行的先后顺序不会乱。

9. 界面缩放、使用说明与捐助

  • 按钮大小（界面缩放）：工具栏上的 按钮大小 输入框可填 1.0 ~ 1.5 倍（默认 1.0）。菜单、菜单命令、工具栏按钮、表格文字会整体等比放大，方便视力不佳的老年用户；拖动调节时先显示倍数、松开鼠标后界面才缩放（这样拖动更顺滑，不会抖）；设置会被记住，下次打开依然生效。
  • 使用说明：菜单 帮助 → 使用说明 可随时打开详细的图文说明书（按使用顺序分节讲解，首次使用跟着走一遍即可上手）。
  • 操作日志落盘（可选）：菜单 设置 → 操作日志落盘（默认关闭）。开启后每条操作日志会追加写入程序同目录的 操作日志.txt（超过 2MB 自动轮转为 .1），便于日后检索某次操作做了什么；不想留文件时关掉即可，设置会被记住。
  • 自愿捐助：工具栏上的 ❤ 自愿捐助 按钮内是开发者的微信收款码，感谢您的支持。

四、常见疑问与注意事项

能打开哪些文件？

主要是 CSV 和 TXT。软件会自动识别编码：UTF-8（含 BOM）、UTF-16、以及常见的 GBK/GB18030 中文编码都不乱码。

数据会被修改到原文件吗？

不会。软件是在内存里展示和加工，只有你明确点“导出数据”或“拆分数据”生成新文件后，才会写出结果，原文件始终不会被改动。列操作都支持撤销/恢复。

提示“按字段拆分唯一值过多”是什么？

当按字段拆分会生成超过 2 万个文件时，软件会拒绝，防止一次生成海量文件。建议改用“按行数拆分”。

为什么 XLSX 导出结果被分成多个表（sheet）？

因为 Excel 单个工作表最多只能放约 104 万行。超过这个数量时软件会自动拆分多个 sheet，保证数据不丢失。

软件需要安装吗？

不需要。它是单个 exe 文件，拷贝到电脑上双击就能运行，旧的 Windows 7 也能用，无需安装任何运行库。

打开超大文件慢，怎么办？

首次打开时会先建立行索引，几秒即可；打开超大文件（几个 G）时请耐心等待进度条完成。若文件非常大，建议先用“按行数拆分”把大文件切小，更方便处理。
