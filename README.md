# 宿经03超大CSV文件实用编辑器（Rust 重构版）

原 Python/PyQt6 版（`1.3_nodask.py`，4227 行）的 Rust 重构，专注超大 CSV 文件（实测 6.5GB / 901 万行 / 55 列）的读取、预览、筛选、拆分、列操作、哈希、统计分析（去重 / 分组汇总）与导出。

**关键能力**：打开 6.5GB 文件约 4 秒、峰值内存约 150MB；**兼容 Windows 7 的单文件 exe**（无任何外部 DLL 依赖）。

---

## 一、功能一览

| 功能 | 说明 |
|---|---|
| 打开 CSV | 单文件；智能编码检测（BOM → 严格 UTF-8 → UTF-16 → GB18030 兜底），支持 ANSI/GBK 中文文件与 UTF-16 |
| 多文件合并 | 一次多选或反复「追加选择」多个 CSV；**读取数据前先校验表头**，表头不一致时可只保留相同字段名的字段（交集）合并 |
| 数据预览 | 虚拟化表格（egui_extras），901 万行仅渲染可见部分，流畅滚动；显示行数可选 100/1000/10000/全部 |
| 筛选 | 10 种条件（等于/包含/不包含/大于/小于/大于等于/小于等于/不等于/空值/非空值）+ 且/或组合；并行分块，901 万行秒级完成；数值比较用 i128 精确（19 位卡号不丢精度） |
| 去重（数据分析） | 「提取唯一行（去重）」：在当前筛选结果内按指定字段（可多选）或全部字段判重，保留首次出现的唯一行；完成后弹窗可导出**重复行对应表**（保留行 ↔ 被剔除行 + 判重字段值）供逐条核对 |
| 分组汇总（数据分析） | 「字段分组汇总」：按 1~3 个字段分组，对选定列做行数、求和、均值、最大、最小、计数、去重计数、空值数；求和用**定点十进制精确累加**（大额金额、两位小数不会出现 `…580001` 这类误差）；**最大/最小数值优先，整列无值时按文本顺序比较**（`交易时间` 这类定长文本即可取到最早/最晚）；结果在弹窗内虚拟化查看（可**最小化**为标题栏稍后再导出），可导出 CSV / XLSX |
| 列统计（数据分析） | 「数值列统计」：对选定列（可多选，一次扫描）给出计数、空值数、非数值数、求和、均值、**中位数**、最小、最大、**标准差**（总体，Welford 在线算法）；求和同样定点精确；结果窗与导出方式同分组汇总 |
| 重复情况（数据分析） | 「重复情况统计」：按选定字段（或整行）找出重复的键、各重复几次、重复行占比，明细按重复次数降序；结果窗可一键「**只看重复的行**」或「**只看唯一行**」把结果落回当前视图（判重口径与去重完全一致） |
| 数据质量（数据分析） | 「空值与数据质量统计」：逐列体检 —— 空值数、纯空白数、空值率、含控制字符数（制表符/换行等）、最短/最长/平均长度（按字符数）、超长值数（>255 字符）；可一次「全选」体检整份数据 |
| 透视表（数据分析） | 「透视表」：行字段（1~2 个）× 列字段 × **多项指标**（每项＝值列 × 聚合方式，如「金额求和 + 金额均值 + 笔数计数」，最多 12 项）的交叉表，行末与末行给出「(合计)」（**整体聚合**，均值/计数在合计处也正确）；**规模上限（行组合数 / 列字段取值 / 单元格数）可在参数窗按硬件情况调整**并记忆 |
| 交叉统计（数据分析） | 「交叉 / 关联统计」：看两个字段的对应关系（例「同一卡号对应多少个账号」）—— 判定**一对一 / 一对多 / 多对一 / 多对多**、给出两侧最大对应数，以及每个 A 值对应的 B 值个数与示例 |
| 频次分布（数据分析） | 「频次分布 / Top-N」：统计选定列各取值的出现次数与占比（占比按 **4 位有效数字**显示，低频值不会退化成 0.00），按次数降序取前 N 项（默认 20，可调至 1000），空值归为「(空)」一类，超出部分汇总为「(其余 M 个取值)」，末行「(合计)」用于核对总量；用于找出重复最集中的值（卡号/账号/IP 等）；结果窗与导出方式同分组汇总 |
| 拆分 | 按行数 / 按字段（1~3 列组合）；按字段单遍哈希分组 O(N)，文件数上限保护，重名自动序号；**拆分后逐文件读回核对行数**，日志给出每个文件行数、合计与数据来源的对比结论，并在输出目录自动生成带时间戳的「拆分完整性核对表_时间戳.csv」（不覆盖历史） |
| 列操作 | 拆分字段、合并字段、复制列、插入列、删除列、隐藏/显示列、生成行哈希（md5/sha1/sha256/sha512）；撤销/恢复（命令式，零复制） |
| 导出 | CSV（utf-8-sig 带 BOM）/ XLSX（全文本导出，防科学计数法与精度丢失；超过 1,048,576 行自动分 sheet） |
| 其他 | 操作日志（可选落盘到 exe 同目录的「操作日志.txt」，2MB 自动轮转）、内存占用显示、示例数据、使用说明（帮助菜单）、自愿捐助、界面等比缩放 1.0~1.5 倍、关于 |

## 二、与 Python 版（1.3_nodask）的差异与改进

### 修复的逻辑问题
1. **编码检测**：Python 版"chardet + GB18030 优先"会把 UTF-8 文件误判为 GB18030 产生**静默乱码**（实测证实）。Rust 版改为"严格 UTF-8 验证优先、GB18030 兜底"，UTF-8 文件绝不会再乱码；latin1 兜底导致的编码误判不重试问题一并消除。
2. **拆分性能**：Python 版按字段拆分对每个唯一值全表扫描 `df[df[col]==value]`（O(N×U)）；Rust 版单遍哈希分组 O(N)。多列组合键用 `\x1F` 连接，文件名清理覆盖控制字符。
3. **XLSX 行数上限**：Python 版 901 万行导出 XLSX 直接崩溃（Excel 单表上限 1,048,576）；Rust 版自动分多个 sheet。
4. **长数字**：Rust 版 XLSX 采用**全文本导出**（所有列按文本 `@` 格式写入），长数字、前导零、大整数一律不丢精度；不再沿用 Python 版"列名关键词 + 数据采样"的启发式长数字列识别（该启发式会漏判无关键词的列）。
5. **撤销/恢复**：Python 版每次操作深拷贝整个 DataFrame（20 步历史），6.5GB 文件单次拷贝即 OOM；Rust 版为命令式操作栈（记录操作描述），零复制。
6. **错误处理**：Python 版大量 `except: pass` 吞错；Rust 版全部显式错误信息进入日志。
7. **死代码**：Python 版 ThreadPoolExecutor/ProcessPoolExecutor 从未使用；Rust 版按需使用 std::thread。

### 性能数据（实测 jymxb.csv：6.5GB / 9,013,661 行 / 55 列 / UTF-8）
| 指标 | Python 1.3 | Rust 版 |
|---|---|---|
| 打开+行索引 | 数分钟（pandas 全量载入） | **4.1 秒** |
| 峰值内存 | 15GB+（pandas 全量，低配机直接 OOM） | **148 MB** |
| 全量筛选 | 分钟级（逐条件全列转换） | 并行秒级 |
| 文件体积 | ~300MB（PyInstaller 单文件） | **7.4 MB** |

## 三、系统要求与 Win7 兼容

- **运行时**：Windows 7 SP1 及以上（x64），无需安装任何运行库。
- 单文件 exe 导入表仅含 Win7 内置系统 DLL（kernel32 / msvcrt / user32 / gdi32 / advapi32 / shell32 / ole32 / opengl32 / dwmapi / uiautomationcore 等，实测 16 个），无 UCRT、无 API-set 依赖。
- 中文界面使用系统字体（微软雅黑/黑体）。
- 图形渲染依赖 OpenGL（Win7 显卡驱动通常支持；软件渲染亦可回退）。

> 说明：标准 Rust std 自 1.58+ 静态导入 Win8/Win10 API，普通编译产物在 Win7 无法加载。本项目使用 Rust 官方 Tier 3 目标 `x86_64-win7-windows-gnu` + nightly `build-std` 重新编译标准库，才得到真正 Win7 兼容的产物（已验证导入表）。构建环境为本机（Win10/11），**建议在 Win7 真机/虚拟机做最终验收**。

## 五、使用说明

1. **打开**：点击「选择CSV文件」选择 CSV（或 .txt）；打开过程在后台线程执行，进度窗口显示进度与预计信息。
   **多文件合并**：点「选择多个CSV文件（合并）」或菜单「文件 → 打开多个CSV文件（合并）」，可一次多选、也可反复「追加选择文件」；软件先校验各文件表头（一致 / 仅顺序不同 / 有差异），表头不一致时可勾选「只保留相同字段名的字段」按交集合并，完成后自动作为当前数据打开。
2. **预览**：默认显示前 100 行，可切换 1000/10000/全部（全部为虚拟滚动）。
3. **筛选**：筛选窗口里选字段/条件/值/逻辑（且/或组合），点「应用筛选」；命中行显示在预览区，可「导出数据」保存结果。工具栏「🧹 清除筛选」与窗口内「清除筛选」等价，一键恢复完整数据。
4. **拆分**：右侧「数据拆分」标签：按行数（每批行数）或按字段（勾选 1~3 个字段），选 CSV/XLSX 输出，选择保存文件夹执行。
5. **列操作**：右侧「列操作」标签：拆分字段/合并字段/生成行哈希/复制列/插入列/删除列/隐藏列/显示列，支持撤销/恢复。
6. **导出**：顶部「导出数据」导出当前筛选视图为 CSV/XLSX；XLSX 超 104 万行自动分 sheet。
7. **界面缩放**：工具栏「日志」右侧的「按钮大小」填 1.0~1.5 倍（默认 1.0），菜单/菜单命令/工具栏按钮/表格文字整体等比放大，设置会被记住。
8. **使用说明 / 捐助**：菜单「帮助 → 使用说明」打开分节图文说明；工具栏「❤ 自愿捐助」按钮显示微信收款码。
9. **数据处理工具栏**：主工具栏下方的一条工具栏，汇集「数据处理」菜单的全部命令（拆分数据、列操作、撤销/恢复、清理筛选缓存、文件信息）；菜单「工具 → 数据处理工具栏」可显示/隐藏（默认显示，显示时菜单项后带 ✔）。
10. **数据分析工具栏 / 提取唯一行（去重）**：工具栏与菜单「数据分析 → 提取唯一行（去重）…」同名同功能。在弹出的窗口中选择判重字段（不选 = 按全部字段判重，支持全选/全不选），执行后在**当前筛选结果**范围内保留唯一行（保留每条重复记录中首次出现的那行），结果作为新的当前视图 —— 后续导出、拆分、统计都基于唯一行；用「清除筛选」可回到全量数据。菜单「工具 → 数据分析工具栏」可显示/隐藏该工具栏（默认显示，显示时带 ✔）。
11. **字段分组汇总**：工具栏「📊 分组汇总…」或菜单「数据分析 → 字段分组汇总…」。在窗口中选 1~3 个分组字段（槽位 1 为主分组字段；「（不使用）」表示不参与分组），再为若干列添加聚合方式（求和/均值/最大/最小/计数/去重计数/空值数，同一列可添加多个），点「开始汇总」。统计范围是**当前筛选结果**（未筛选则为全部数据），每组自动给出「行数」。
    - 结果窗用虚拟化表格展示（可拖动列宽、滚动查看全部行），顶部显示「统计范围行数 → 分组数」；若某列存在无法解析为数值的内容，会用橙色提示「N 个非数值未参与求和/均值/最大/最小」。
    - 求和是**定点十进制精确累加**：金额、数量这类数据（含两位小数）不会出现小数点后多出一串位数的误差；只有数据里出现科学计数法写法或超过 9 位小数时才会回退浮点累加。
    - 结果窗工具栏有「**最小化**」按钮：点击后窗口收起成一条标题栏（统计结果仍在程序里），想稍后再导出时点标题栏左侧的三角或双击标题栏即可展开，不会丢结果。
    - 「导出 CSV… / 导出 XLSX…」把结果表另存（CSV 带 BOM、XLSX 全文本；行号从 1 开始）。导出后结果窗保持打开，可继续查看或再导出另一种格式；若不小心关掉了结果窗，可用菜单「数据分析 → 查看上次汇总结果…」重新打开。
    - 统计**不改变**当前数据视图（与去重不同），可以反复调整参数再汇总；开始与完成时的参数、范围、分组数都会写入操作日志。
    - 注意：派生列（拆分字段/合并字段/复制列/生成行哈希等新列）不参与统计；分组数超过上限（默认 20,000）时会提示改用取值较少的字段 —— 窗口底部「规模上限」可把上限调大（见第 16 条说明）。
12. **数值列统计**：工具栏「📈 列统计…」或菜单「数据分析 → 数值列统计…」。在窗口中勾选要统计的列（支持全选/全不选），点「开始统计」，结果窗每行是一列，给出：行数、计数（非空）、空值数、非数值数、求和、均值、**中位数**、最小、最大、**标准差**。
    - 统计范围同样是**当前筛选结果**（未筛选则为全部数据），一次扫描算完所有选中列。
    - 求和/均值用定点十进制精确处理；**标准差是总体标准差（分母 n）**，如需样本标准差用结果乘以 `sqrt(n/(n-1))`（结果窗会提示这句）。
    - **中位数需要保留该列的原始数值**：为保证内存在可控范围，单列最多保留 1000 万个值、所有列合计 2000 万个值（按列数均分）。超出时该列中位数显示「—」，并在结果窗与日志中提示先用筛选缩小范围或减少列数（不会悄悄给近似值）。
    - 数值判定与筛选一致：`NaN`、`±inf`、文字都算「非数值」，不计入求和/均值/中位数/极值；某列同时有数值和非数值时，结果窗会提示「N 个非数值未参与计算」。
    - 结果窗同样支持「最小化」与「导出 CSV / XLSX」；用菜单「数据分析 → 查看上次统计结果…」可回看最近一次统计（分组汇总或列统计）。
13. **频次分布 / Top-N**：工具栏「🔢 频次分布…」或菜单「数据分析 → 频次分布 / Top-N…」。勾选要统计的列（可多选）并设置「每列显示前 N 项」，点「开始统计」，结果表每行是一个取值：列名、排名、取值、出现次数、占比(%)。
    - 典型用途：找出**出现次数最多的值**（如卡号/账号出现次数最多的前 20 条，定位重复集中点）。
    - 排序规则：出现次数从多到少；次数相同时按取值升序（结果稳定可复现）。
    - 空值（含全空白）归为一类 **「(空)」** 参与排名与占比；占比分母是**统计范围行数**（含空值行）。
    - 超出前 N 项的取值不逐个列出，而是追加一行 **「(其余 M 个取值)」** 汇总其次数与占比；每列**末行是「(合计)」**（出现次数 = 统计范围行数、占比 100%），用它核对总量最直观 —— 各行占比（含「其余」行）相加即 100%。
    - 占比按 **4 位有效数字** 显示并去掉尾随零：`50`、`33.33`、`0.0475`、`0.004748` —— 即使某值在百万行里只出现几十次，也能看清它的量级（固定 2 位小数会全显示成 `0.00`）。逐行占比因舍入相加可能与 100% 略有出入，「(合计)」行给的是精确值。
    - 按**原值**统计（区分大小写与首尾空格，与去重判重一致）：若同一列存在 `北京` 与 `北京␣`，会算作两个不同取值。
    - 若某列的不同取值过多（超过内存上限：单列 100 万、所有列合计 300 万，按列数均分），会**拒绝统计并提示先用筛选缩小范围** —— Top-N 依赖完整计数，丢弃部分取值会得出错误的"最高频"结论，所以宁可拒绝也不给错的结果。
    - **按频次筛选写回视图**：结果窗底部可直接填阈值（默认 2）点「**筛出这些行**」，当前视图即切换为"该列取值出现次数 ≥ 阈值"的**全部行**，并**按取值分组排列**（同一个取值的行挨在一起、次数多的组在前，行号列仍是原始行号）—— 挑出高频记录逐条核对；用「🧹 清除筛选」恢复全部。该按钮需要频次分布**只统计了一列**（多列时不显示）。

14. **重复情况统计**：工具栏「🔁 重复情况…」或菜单「数据分析 → 重复情况统计…」。选择判重字段（**一个都不勾 = 按整行判重**），设置明细列出的重复键个数（默认 100），点「开始统计」。
    - 顶部摘要给出：统计范围行数 → 不同键个数、重复键个数、重复行数与占比。
    - 明细表每行是一个重复键：判重字段取值、出现次数、重复行数（= 出现次数 − 1）、占行数(%)、首次出现行号（从 1 开始）；按重复次数降序。
    - 结果窗里可一键 **「只看重复的行」**（切到重复键涉及的全部行，含首次出现那行）或 **「只看唯一行」**（= 提取唯一行的结果）；切换后用工具栏「🧹 清除筛选」可恢复全部数据。
    - 「只看重复的行」的结果**按重复键分组排列**：同一个键的各行紧挨着（组间按重复次数降序、组内按行号升序，与明细表顺序一致），预览区里一眼就能看出谁和谁重复；行号列显示的是**原始行号**，方便回原表核对。
    - 判重口径与「提取唯一行（去重）」**完全一致**（按原值组合比较、保留首次出现的行），两者可交叉验证。
    - 若不同键个数超过上限（200 万），会提示先用筛选缩小范围或减少判重字段（不给不完整的结果）。
15. **空值与数据质量统计**：工具栏「🔬 数据质量…」或菜单「数据分析 → 空值与数据质量统计…」。勾选要检查的列（想知道整份数据的质量就点「全选」），点「开始检查」，结果每列一行：
    | 指标 | 含义 |
    |---|---|
    | 空值数 | 完全没有内容（长度 0）的行数 |
    | 纯空白数 | 看着有内容、其实全是空格/制表符的行数 |
    | 空值率(%) | (空值数 + 纯空白数) ÷ 行数 —— 业务上「只有空白」通常等同于空 |
    | 含控制字符数 | 值里出现制表符、换行等控制字符的行数（银行数据的尾随制表符会在这里显形） |
    | 最短/最长/平均长度 | 按**字符数**统计（中文算 1 个字符），只算非空值 |
    | 超长值数(>255) | 字符数超过 255 的值个数（多数系统的字段长度上限） |
    - 结果窗顶部会汇总「多少列存在空值/纯空白、多少列含控制字符、多少列有超长值」，一眼看清哪些列需要清洗。
16. **透视表**：工具栏「🧮 透视表…」或菜单「数据分析 → 透视表…」。选择 1~2 个**行字段**、1 个**列字段**，再添加**若干项指标**（每项 = 值列 × 聚合方式，如「交易金额-求和」「交易金额-均值」「交易卡号-计数」，最多 12 项），点「生成透视表」。
    - 结果是一张交叉表：行 = 行字段的取值组合，列 = 列字段的各个取值（按取值升序，空值是「(空)」列），单元格 = 值列在该组合下的聚合结果。
    - 每行末尾与最后一行是 **「(合计)」**，它们是**整体聚合**（不是把各行数值相加）——所以均值、计数在合计处依然正确。「没有数据的单元格」留空，与「聚合结果为 0」区分开。
    - **多项指标**：只有一项指标时表头就是列取值本身（如 `01`）；两项以上时表头是 `列取值-值列(聚合)`（如 `01-交易金额(求和)`），合计列是 `(合计)-交易金额(求和)`。同一列可添加多种聚合（如金额同时求和与均值），也可添加不同列。
    - **规模上限可按硬件调整**（参数窗底部「规模上限」）：行组合数上限（默认 20000）、列字段取值上限（默认 200）、单元格数上限（默认 500000），并提供「恢复默认」；界面实时给出**粗估最大内存**（每个格子每项指标约 100 字节）。设置会被记住，下次打开沿用。超过上限时会提示"调大上限 / 减少行字段 / 先筛选"，而不是直接失败。
    - 列字段的不同取值若确实很多（例如卡号），仍建议改用「字段分组汇总」按两个字段分组，或先筛选缩小范围 —— 列太多既看不清也意义有限。
    - 例：行 = 数据来源_银行名称、列 = 交易是否成功、值 = 交易金额(求和) → 每家银行各状态的金额合计。
17. **交叉 / 关联统计**：工具栏「🔗 交叉/关联…」或菜单「数据分析 → 交叉 / 关联统计…」。选 A、B 两个字段，点「开始统计」。
    - 输出**关系判定**：一对一（互相唯一对应）/ 一对多（一个 A 对应多个 B）/ 多对一（多个 A 指向同一个 B）/ 多对多；同时给出两个方向的最大对应数。
    - 明细每个 A 一行：行数、对应 B 的不同值数、B 取值示例（最多 5 个），按「对应 B 的不同值数」从多到少排列 —— 排在最前面的就是"发散得最厉害"的 A，通常是排查重点。
    - 典型用途：「同一卡号对应多少个账号」「同一 IP 对应多少个身份证」——判断是否存在一对多/多对多的异常关联。
    - 按原值比较（与去重一致），空值也是一种取值；A 的不同取值上限 20000、不同组合上限 100 万（超出提示先筛选）。

18. **各统计功能的「规模上限」都能按硬件调整**：分组汇总 / 数值列统计 / 频次分布 / 重复情况 / 交叉统计的参数窗底部都有「规模上限」区（透视表的在窗内），把它们调大就能处理更大规模的数据，代价是内存占用上升（界面会给出粗估）。设置会被**记住**（重启后沿用）；只有在你改过默认值时才在操作日志里记一笔，便于事后审计。超过上限时各项统计都会提示「调大上限 / 减小统计维度 / 先筛选缩小范围」，而不是只给一个死路。

## 七、已知限制

- 按字段拆分对唯一值超过 20,000 个的字段会拒绝（提示改用按行数拆分），避免生成海量文件。
- 分组汇总的分组数上限默认 20,000（**可在参数窗「规模上限」里按硬件调大**）；单个「去重计数」最多保存 200,000 个不同值，超出后结果标注为 `>=N`。
- 分组汇总只接受原始列（派生列不参与统计），聚合按文本数值语义解析（与筛选一致），非数值单独计数并在界面/日志中提示。
- 分组汇总的求和/均值用**定点十进制**精确累加（小数位上限 9 位）；若某列出现科学计数法写法（如 `1e5`）或超过 9 位小数，该列会整体回退浮点累加——结果仍可用，但可能出现极小的尾差（此时请以原始字段的写法为准）。
- 数值列统计的**中位数**需要保留原始数值：默认预算为所有列合计 2000 万个（按列数均分，约 160MB），**可在参数窗调整**。超出时该列中位数显示 `—`（不提供近似值），可先筛选缩小范围、减少列数或调大预算。
- 数值列统计的**标准差是总体标准差（分母 n）**；样本标准差 = 结果 × `sqrt(n/(n-1))`。
- **最大/最小（分组汇总、列统计、透视表通用）**：先按数值比较；若该列**整列都没有可解析的数值**（如 `2026-01-05 10:30:00` 形式的交易时间），则退化为**按文本（字典序）比较** —— 定长日期时间文本的字典序就是时间先后，因此能直接取到"最早/最晚"。混合列（既有数字又有文字）仍按数值比较，文字不参与并在结果窗提示。
- 频次分布的**不同取值上限**：默认所有列合计 300 万个（按列数均分），**可在参数窗调整**。超出时报错并提示「调大上限 / 先筛选缩小范围」（不提供不完整的频次结果）。
- 频次分布按**原值**统计（区分大小写与首尾空格），空值归为「(空)」；占比分母是统计范围行数，显示为 4 位有效数字（去尾零）。
- 重复情况统计的**不同键上限**默认 200 万（**可在参数窗调整**，超出报错并提示）；与去重一致，为**单线程**（键表需全局唯一、首次出现行号依赖全局顺序），200 万行按 1~2 列判重约 0.6 秒。
- 数据质量统计的「含控制字符」按 Unicode 控制字符判定（含制表符 `\t` 与字段内换行）；「超长值」阈值固定为 255 字符。
- 透视表：行字段 1~2 个、指标最多 12 项；**规模上限可在参数窗调整**（默认：行组合 20000 / 列字段取值 200 / 单元格 50 万；调大后内存占用相应增加）；**不支持「去重计数」**（每个格子一个集合，内存不可控）——需要该口径请用「字段分组汇总」按两个字段分组。透视表与交叉统计均为**单线程**（需要行/列/单元格三级映射或双向映射）。
- 交叉/关联统计：A 的不同取值上限默认 20000、不同 (A,B) 组合上限默认 100 万（**均可在参数窗调整**，超出提示先筛选缩小范围）；B 取值示例每行最多列 5 个。
- XLSX 导出行数超过 1,048,576 时自动分 sheet（每 sheet 满额即开新 sheet）。
- XLSX 为**全文本导出**：所有单元格按文本写入（Excel 中数字左对齐、不参与求和等数值计算），以此换取长数字、前导零与大整数的零精度损失。
- UTF-16 编码文件会整体转码载入内存（此类文件通常较小）；超大 UTF-16 文件建议先转码。
